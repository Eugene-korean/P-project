# 실험 조건 목록

> 자동 생성 문서. `configs/` 아래 JSON에서 만들어진다. 고치려면 JSON을 고치고 push한다.
> main에 `configs/**.json`을 push하면 공용 PC에서 그 파일이 자동 실행되고, 이 문서도 다시 만들어진다.

phase 이름을 누르면 조건별 상세가 나온다. 측정 횟수 = 모델 수 × 길이 개수 × 반복 (한 번마다 재계산·저장·복원을 모두 잰다).
